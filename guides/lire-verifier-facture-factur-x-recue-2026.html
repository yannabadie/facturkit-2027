Comment ouvrir, lire et vérifier une facture Factur-X reçue d'un fournisseur (2026–2027)

Publié le 20 novembre 2026 • Guide pratique TPE & indépendants • Informations générales, ne constituant pas un conseil juridique ou fiscal

Depuis le 1er septembre 2026, toutes les entreprises établies en France — y compris les micro-entreprises et TPE — sont soumises à l'obligation de réception des factures électroniques. Si vos grands fournisseurs (télécoms, énergie, SaaS, grossistes) vous transmettent déjà des factures Factur-X, voici comment vérifier concrètement ce que contient le fichier avant de le régler et de l'archiver.

1. Ce qui se cache dans un PDF Factur-X reçu

Visuellement, une facture Factur-X s'ouvre dans n'importe quel lecteur PDF (Aperçu macOS, Edge, Chrome, Adobe Reader). Sa particularité technique réside dans le conteneur PDF/A-3 qui embarque une pièce jointe interne nommée factur-x.xml (ou zugferd-invoice.xml / xrechnung.xml pour certains fournisseurs européens).

En cas de divergence entre le texte affiché sur le PDF et les données structurées du XML, ce sont les données structurées qui font foi dans le circuit de facturation électronique : il est donc essentiel de ne pas se limiter au seul visuel PDF.

2. Inspecter le XML en local (sans fuite de données fournisseurs)

Envoyer des factures fournisseurs contenant vos prix d'achat, IBAN et SIREN sur des validateurs web distants expose des données commerciales sensibles. Deux méthodes 100 % locales permettent un contrôle immédiat :

  1. Dans votre navigateur (0 installation) : glissez-déposez votre fichier PDF/A-3 ou XML dans l'Inspecteur Factur-X gratuit FacturKit. Le moteur extrait le flux binaire FlateDecode localement sur votre poste, vérifie la clé Luhn des SIREN, les totaux EN 16931 BR-CO et les règles françaises XP Z12-012.
  2. En ligne de commande (batch / CI) : utilisez notre validateur Python CLI open source pour contrôler un dossier entier de factures fournisseurs avant import comptable.

3. Les 5 contrôles indispensables avant mise en paiement

  • Présence réelle de factur-x.xml : certains fournisseurs renomment un PDF simple en « Factur-X » sans pièce jointe XML valide.
  • Concordance HT / TVA / TTC : vérifiez que le net à payer (DuePayableAmount) dans le XML correspond exactement au montant indiqué sur le PDF visuel.
  • Identifiants SIREN & TVA : contrôlez le SIREN vendeur et votre propre SIREN acheteur (guide des 4 nouvelles mentions 2026–2027).
  • Code TVA ou exonération : vérifiez le taux appliqué ou la mention franchise en base art. 293 B du CGI si le fournisseur est non assujetti.
  • Archivage intact : conservez le fichier PDF/A-3 original reçu depuis votre Plateforme Agréée sans jamais le « réimprimer en PDF », ce qui détruirait la couche XML.

Questions fréquentes

Quelle est la différence entre un PDF classique et une facture Factur-X reçue ?

Un fichier Factur-X respecte la norme PDF/A-3 et embarque en pièce jointe interne un fichier structuré factur-x.xml conforme à la norme européenne EN 16931 (UN/CEFACT CII).

Puis-je vérifier une facture fournisseur sans envoyer le PDF sur Internet ?

Oui. L'inspecteur binaire gratuit FacturKit décompresse le PDF/A-3 localement en JavaScript dans votre navigateur : aucun fichier ne quitte votre ordinateur.

Faut-il conserver le PDF/A-3 original après réception ?

Oui : archivez toujours le fichier original intact transmis par votre Plateforme Agréée afin de préserver la pièce jointe XML structurée.
